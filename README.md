# Mente em Equilíbrio — site educativo
Site responsivo sobre saúde mental, ansiedade e stress nos estudantes.

## Como abrir
1. Extraia o ficheiro ZIP.
2. Abra a pasta `site_saude_mental_estudantes`.
3. Abra `index.html` num navegador.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Carregue `index.html`, `style.css`, `script.js` e este README.
3. Em Settings > Pages, escolha a branch `main` e a pasta `/root`.
4. Guarde e aguarde a publicação.

O site é educativo e não substitui aconselhamento profissional. Fontes de aprofundamento estão no rodapé.
